# ICEP website

Website for Imperial College Electric Propulsion.

Live address: https://dce521.github.io/icep-website/

This is a static website. Edit `index.html`, `style.css`, and files in `assets/`. No installation or build command is required.

## Publishing

In repository Settings > Pages, choose Deploy from a branch, select `main` and `/ (root)`, and save. Changes committed to `main` then publish automatically.
